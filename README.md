# ORBITA Assistant

Локальный помощник для выбора следующего сообщения покупателю. Приложение не подключается к Авито и ничего не отправляет: кнопка копирования только кладёт подготовленный текст в буфер обмена.

## Разработка

- Требуется Node.js 24.
- `npm ci` — установить зависимости.
- `npm run dev` — запустить Vite для разработки.
- `npm run lint`, `npm run typecheck`, `npm run test`, `npm run build`, `npm run audit:public`, `npm run audit:budget` — проверки.
- `npm run test:e2e` — сценарии Playwright; перед запуском установите браузер командой `npx playwright install chromium`.
- `npm run audit:lighthouse` — пересобрать проект, измерить Lighthouse mobile и записать результат в `docs/performance.md` (требует Chromium и доступа к npm для Lighthouse CLI 13.5.0).

Сборка использует `base: /orbita-assistant/` для GitHub Pages проекта `yarrobong/orbita-assistant`.

## Данные и безопасность

Избранное, последний экран и отметки о проблеме/запрошенном отзыве хранятся только в этом браузере. Поля, адреса, контакты и остальные отметки статусов не сохраняются после закрытия вкладки; при продолжении проверки нужно выполнить заново. Не вводите имена покупателей, телефоны покупателей или содержание переписки. Наличие товара, доступность доставки, цену, совместимость и статус заказа всегда проверяйте вручную. Не включайте в публичные файлы адрес или телефон человека на выдаче. `npm run audit:public` проверяет шаблоны и собранные файлы на эти данные.

## Публикация

Workflow `Deploy GitHub Pages` проверяет сборку и публикует `dist/` из ветки `main`. Для репозитория выберите `Settings → Pages → Build and deployment → GitHub Actions`. Перед публикацией убедитесь, что репозиторий не содержит приватных контактов или клиентских данных.
