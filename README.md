# ORBITA Assistant

Локальный помощник для выбора следующего сообщения покупателю. Приложение не подключается к Авито и ничего не отправляет: кнопка копирования только кладёт подготовленный текст в буфер обмена.

## Разработка

- Требуется Node.js 24.
- `npm ci` — установить зависимости.
- `npm run dev` — запустить Vite для разработки.
- `npm run lint`, `npm run typecheck`, `npm run test`, `npm run build`, `npm run audit:public` — проверки.
- `npm run test:e2e` — сценарии Playwright (требуют установленных браузеров).

Сборка использует `base: /orbita-assistant/` для GitHub Pages проекта `yarrobong/orbita-assistant`.

## Данные и безопасность

Настройки и отметки воронки хранятся только в этом браузере и не синхронизируются между устройствами. Не вводите имена покупателей, телефоны или содержание переписки. Наличие товара, доступность доставки, цену, совместимость и статус заказа всегда проверяйте вручную. Не включайте в публичные файлы адрес или телефон человека на выдаче. `npm run audit:public` проверяет шаблоны и собранные файлы на эти данные.

## Публикация

GitHub Actions публикует production-сборку `dist/` на GitHub Pages после проверок из CI. В репозитории Pages выберите `Settings → Pages → Build and deployment → GitHub Actions`. Перед публикацией убедитесь, что репозиторий не содержит приватных контактов или клиентских данных.
